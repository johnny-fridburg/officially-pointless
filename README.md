# Officially Pointless

A sample-only storefront for fictional office gifts, hosted on Azure Static Web Apps. The proposed Unnecessary Promotions offline gift kit is $19 USD. Purchases remain closed until seller, policy, support, authoritative provider test-delivery and final owner acceptance requirements are complete.

The current website ships no certificate editor, printable SVG/PDF, playable department or public contribution engine. The former editor route shows a purchase-required notice, and the community API closes reads and writes before initializing storage or identity. Future departments are upcoming paid ideas, not available purchases. No online entitlement is granted by this release or by client payment flags.

This public repository contains only allowlisted deployable files, closed APIs, verification checks and the deployment workflow. Private source and paid ZIPs belong to the separate private repository/provider delivery area. The reviewed raster cover is a sample image for viewing; no commercial redistribution license is granted. Historical public commits and prior downloads remain copyable.

Run `node --test`, `node scripts/verify-public-artifact.js site`, and `node scripts/verify-public-repository.js --head` before deployment. Install hooks with `git config core.hooksPath .githooks`; the index and outgoing commit guards reject unreviewed paths, nonregular entries, unexpected formats, archives and recognizable credentials. The sole allowed sample image retains its reviewed SHA-256 pin. Current artifact checks reject the retired printable file paths. Policy changes require independent review; exact committed-tree CI passes before Azure upload.

The checks do not provide DRM or prove artwork provenance. Deployment uses pinned upstream actions and the existing sponsored Azure resource.
